I want to make a new game like Guitar Hero (https://en.wikipedia.org/wiki/Guitar_Hero), the new game I want to create is called Code Hero.  

Language keywords should slowly drop from the screen and the idea is that the player has to type that keyword before it reaches the bottom.  You get 5 lives. After 10 keywords then you progress to the next level where the words are slightly faster and more advanced.  Keywords can come from C#, TypeScript, HTML, CSS, JavaScript, Go, python

When a letter is typed correctly is typed correctly it's highlighted in the keyword. When the full word is typed correctly there is cool special effect like lightning. The game should be fun to play, visually colorful, vibrant and should be playable either via a keyboard.

Cool intro and game play. Tech stack: React, TypeScript, Phaser (https://phaser.io/).  Latest versions, modern and secure development practices
